# Academia Littera

Site oficial da **Academia Littera**, escola de idiomas dedicada ao ensino de línguas com clareza, acompanhamento e atenção à trajetória de cada estudante.

## Sobre o projeto

Este repositório contém o site institucional da Academia Littera. A página apresenta a proposta da escola, informações sobre os cursos e canais de contato para quem deseja tirar dúvidas ou conhecer as opções de matrícula.

## Tecnologias

- HTML
- CSS
- JavaScript

O site foi desenvolvido como uma página web responsiva, com estilos e recursos organizados no arquivo `index.html`.
